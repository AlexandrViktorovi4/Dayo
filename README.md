# Dayo

**Dayo** — офлайн-планировщик для задач, заметок и итогов дня. Приложение создано на Flutter и хранит пользовательские данные локально на устройстве.

## Возможности

- План на день, задачи с подзадачами и сортировкой.
- Повторяющиеся задачи.
- Календарь с переходом между днями и аналитикой прогресса за неделю, месяц и год.
- Заметки, настроение и оценка продуктивности за день.
- Локальные напоминания и настройки уведомлений.
- Профиль с выбором аватара и темой оформления.
- Экспорт и восстановление резервной копии.

## Технологии

- Flutter и Dart
- SQLite через `sqflite`
- `table_calendar` и `fl_chart`
- `flutter_local_notifications`
- `shared_preferences`

## Запуск

Требуется Flutter SDK с Dart `3.9.2` или новее.

```bash
flutter pub get
flutter run
```

## Проверки

```bash
flutter analyze
flutter test
```

Для локальной Android-сборки:

```bash
flutter build apk --debug
```

## Хранение данных

Dayo работает без аккаунта и облачной базы: задачи, профиль и записи дня сохраняются локально. Резервную копию можно создать и восстановить в приложении. Перед удалением приложения рекомендуется сохранить копию данных.

## Статус публикации

Проект подготовлен для портфолио, но перед выпуском Android-релиза необходимо заменить временный `applicationId` и настроить отдельную release-подпись.
